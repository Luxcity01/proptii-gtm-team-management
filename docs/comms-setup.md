## 2. Link code format

Agree this with the Head of Engineering, because their sign-up links (task w0h) and the referral codes from week 2 (task w2h) must use it too.

**Format:** `type-nn` for a source, plus an optional post suffix: `type-nn-wNx`

- `type`: who or where the landlord came from (see the table below).
- `nn`: a two-digit number, given out in order and recorded in the code register below.
- `wNx` (posts only): the week number, plus a letter for each post that week. For example, `li-01-w1a` is the first post of week 1 on the company LinkedIn page.

**Rules:**

- Lowercase letters, numbers and hyphens only.
- Never put a person's or partner's name in the code, because codes show up in public links.
- A code is never reused, even after a partner stops referring.
- In links, the code goes in a `ref` parameter: `https://[sign-up URL]?ref=broker-03`

**Types, and the "How they arrived" option on the account log each one maps to:**

| Type | Used for | Account log source |
|---|---|---|
| `dp` | Design partner | Design partner |
| `broker` | Buy-to-let mortgage broker | Broker referral |
| `acct` | Landlord accountant | Accountant referral |
| `fbgroup` | Facebook landlord group | Landlord group |
| `forum` | Landlord forum | Landlord group |
| `reddit` | Reddit | Landlord group |
| `ll` | Introduced by another landlord (referral codes) | Landlord referral |
| `net` | Our own personal network | Personal network |
| `li` | Company LinkedIn page | Inbound |
| `x` | X | Inbound |
| `ig` | Instagram | Inbound |
